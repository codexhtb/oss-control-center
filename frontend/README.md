# OSS Control Center Web — Phase 1.4 Stage 3B

Интерфейс React/TypeScript использует только `/api/v1` на том же origin. Он включает вход и выход через серверную cookie-сессию, обзор на основе реальных API, реестр с серверной пагинацией, создание `MANUAL`, `INTERNAL` и `SUBSCRIBER_LINKED`, карточку заявки с комментариями, назначением, ручной диагностикой, решениями, закрытием и историей. Права проверяет backend; UI скрывает недоступные действия. Для связанных заявок браузер передаёт только `lookup_id` и выбранные ID услуги/подключения, а snapshot формирует сервер.

Главный адрес из MGMT-сети: **https://172.17.7.2:8443/**. Настройка доверия локальному CA, отдельный Compose project, запуск, остановка и тесты описаны в [инструкции dev-окружения](../docs/operations/dev-lab.md).

## Локальная разработка

Node.js 24, пакеты устанавливаются только в `frontend/node_modules`:

```bash
cd /opt/oss-control-center/frontend
npm ci
npm run dev
npm run typecheck
npm test -- --run
npm run build
```

Vite слушает `127.0.0.1:5173` и предназначен для локальной отладки. Настроенный proxy отправляет только `/api/v1` на dev API. Удалённый доступ с Windows выполняется через HTTPS Compose project, а не через опубликованный Vite dev server.

Сессионный токен остаётся в HttpOnly cookie. CSRF cookie используется только для `X-CSRF-Token`; ответы запрашиваются с `cache: no-store`, клиентский query cache очищается при выходе. Пароли не сохраняются приложением в localStorage, sessionStorage или собственных cookie. Форма входа использует стандартные `name`, `id`, `autocomplete` и native submit для менеджеров паролей браузера.

## Границы

Полная карточка Subscriber 360 с контактами, происхождением полей и несколькими IP-группами остаётся Stage 3C. Техническое состояние без независимого источника показывается как `UNKNOWN`. Имя назначенного инженера оператору не выдаётся действующим RBAC-контрактом списка исполнителей, поэтому в реестре он видит сокращённый ID. Менеджер паролей Chromium проверен по структуре формы; prompt сохранения и автоподстановку на рабочем компьютере владелец проверяет вручную.
