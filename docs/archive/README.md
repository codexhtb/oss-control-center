# Архив документации

Материалы здесь сохранены для истории и происхождения решений. `HISTORICAL` означает, что документ описывает прошлую фазу, snapshot или LAB/dev процедуру и **не является текущей инструкцией**. Перед повторным использованием сверяйте её с кодом и утверждённым runtime.

Во время обновления 2026-11-18 сюда перемещены прежние архитектурные фазовые документы, интеграционные описания, обзоры и runbooks. Архивная копия была проверена на явные IP-адреса; найденные литералы скрыты. Ранее tracked исследования конкретных устройств перенесены сюда с удалением device/port mappings и закрытых признаков топологии. Незатреканные локальные исследовательские файлы сохранены без изменений и не входят в commit или актуальный индекс. Документы, основанные на внешнем инвентаре, требуют отдельного review перед распространением.
