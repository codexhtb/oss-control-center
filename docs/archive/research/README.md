# HISTORICAL — исследования NetUP / LibreNMS

Ранее здесь находились материалы о сопоставлении конкретных устройств и портов. Идентификаторы, адреса и технические признаки закрытой топологии не переносятся в эту документацию. Актуальные mapping decisions существуют только в защищённом registry и требуют отдельной проверки владельцем monitoring.

Эти документы не являются инструкцией или подтверждением текущего соответствия. Для исторического происхождения используйте Git history с соответствующим доступом; для текущей работы — [модуль diagnostics](../../modules/monitoring.md).
