# Архив обзоров

Текущая документация не считает прошлый review доказательством нынешней конфигурации. Сохранённые обзоры NetUP доступны для происхождения решений:

- [Provider 1.0 final review](../archive/reviews/netup-provider-1.0-final-review.md);
- [Provider 1.1 stage 0](../archive/reviews/netup-provider-1.1-stage0.md);

Они помечены HISTORICAL и могут ссылаться на прежние тесты, schema или rollout. Для новой приёмки используйте [текущую матрицу](../architecture/acceptance-and-testing.md), актуальный код и отдельную проверку runtime. Новые review не должны включать secrets, внутреннюю топологию или PII.
