# Reports Phase 1 — общая статистика Service Desk

Источник: только рабочие таблицы PostgreSQL `tickets` и `ticket_history`. Новых таблиц и
миграций нет. `GET /api/v1/reports/general?start=YYYY-MM-DD&end=YYYY-MM-DD&page=1&size=20`
возвращает показатели, дневные ряды, распределения и страницу детализации. Даты включительны
в UTC+3; сервер преобразует их в полуоткрытый интервал UTC. Диапазон ограничен 3660 днями.

Доступ: существующие `tickets.read.all` или `tickets.read.own`. При `read.own` в выборку
попадают только созданные сотрудником заявки. Для роли `operator` тип `INTERNAL` исключён
на сервере из всех показателей, графиков, распределений и детализации независимо от иных
разрешений. Удалённые заявки исключены. Детализация содержит только краткие поля и ссылку
на заявку; авторизация карточки проверяется отдельно действующим API.

Правила расчёта:

- `created`: число уникальных заявок с `tickets.created_at` в периоде.
- `resolved_events`: число событий `ticket_resolved` в периоде. Повторное решение той же
  заявки учитывается снова.
- `closed_events`: число событий `ticket_closed_without_call` и `callback_confirmed_closed`.
- `returned_events`: число событий `callback_returned_engineers`, то есть подтверждённый
  возврат после контрольного звонка.
- `active_now`: текущее число заявок со статусом `OPEN` или `IN_PROGRESS`, без фильтра дат;
  это отдельный срез, а не «созданные за период и ещё активные».
- Среднее до решения: для каждого события `ticket_resolved` время с создания заявки или
  последнего предшествующего возврата `callback_returned_engineers`. Среднее до закрытия:
  время с создания заявки до события закрытия. При отсутствии событий API возвращает `null`.
- Динамика: поступления по `created_at`, закрытия по времени события, календарные дни UTC+3.
- Распределения по типу, текущему статусу и приоритету относятся к заявкам, созданным за
  период. Их суммы равны `created`. JOIN с историей для этих группировок отсутствует.
- Детализация — заявки, созданные за период, отсортированные по `created_at` и ID; страницы
  по 20 записей. Показатели событий могут относиться к заявкам, созданным раньше периода.

Будущие отчёты по сотрудникам, монтажникам, контрольным звонкам и причинам используют
отдельные методы и не входят в этот контракт. Экспорт не реализован.
